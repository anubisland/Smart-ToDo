## Smart-ToDo 1.0.3

### Subtask progress
- Add, remove, and individually check off subtasks while editing a task.
- See completed-versus-total subtask progress directly on task cards.
- Recurring tasks begin each occurrence with a fresh subtask checklist.
- Existing tasks and prior release data are preserved by the database migration.

### Upgrade
This APK keeps the existing signing certificate and can be installed over Smart-ToDo 1.0.2.

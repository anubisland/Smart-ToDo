## Smart-ToDo 1.0.4

### Project overview
- See each project's task count and completion progress on the home dashboard.
- Tap a project card to open its tasks, or choose a project filter on the task screen.
- Search now includes project names.
- Project overview supports Arabic and English.

### Upgrade
This APK keeps the existing signing certificate and can be installed over Smart-ToDo 1.0.3.

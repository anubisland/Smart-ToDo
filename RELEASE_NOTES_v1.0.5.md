## Smart-ToDo 1.0.5

### Guided Pomodoro cycles
- Finishing a focus session prepares a short break; every fourth completed focus session prepares a long break.
- Finishing a break prepares the next focus session.
- The timer never starts the next phase automatically. Start it when you're ready.
- Cycle progress and phase are saved across app restarts. Focus history records completed work sessions.

### Upgrade
This APK keeps the existing signing certificate and can be installed over Smart-ToDo 1.0.4.
